01我们处理哪些信息

元系（OriginLink）是 AI Context Layer，帮助您主动收集和整理网页、文字、图片、本地文件及 AI 对话内容，并生成或交付工作成果。

当您执行收藏、划选、粘贴入库、图片保存、文件导入等操作时，扩展会处理相关文字、图片、文件字节、网页标题与网址、来源信息、项目、标签、摘要、生成结果及素材操作记录。您选取的内容可能包含个人信息、通讯内容或其他敏感信息，请确认有权处理。

扩展保存功能设置、AI 接口地址、模型名称和 API Key，以及自定义 AI/Agent 连接、最近使用目标和本地目录授权信息。

扩展还在本地记录部分功能使用计数及首次使用、最近活动时间，例如划选触发、场景选择、生成和复制次数。项目时间线可记录素材整理、生成及交付事件。代码中未发现这些本地统计自动上传至开发者服务器的路径。

02我们如何存储数据

元系采用本地优先方式。素材、项目、附件缓存及相关记录主要保存在浏览器本地 IndexedDB；会员状态、部分偏好、临时素材篮及功能统计保存在浏览器本地存储。当前扩展不要求注册元系云端账户，检查代码中未发现将素材库整体上传至开发者云端的路径。

AI 设置（包括 API Key、接口地址、模型名称及演示模式设置）保存在 chrome.storage.sync 中，不是仅限当前设备的本地存储。浏览器启用相应同步服务时，这些设置可能经浏览器服务同步至同一账户的其他设备，具体受浏览器规则和同步状态影响。

您授权连接本地文件夹后，扩展可以向该目录写入素材文件、附件和索引。导出、备份及目录内的副本由您管理。浏览器清理、卸载或设备故障可能导致浏览器本地资料丢失；已经导出的文件或目录文件不会因此自动删除。

03我们如何使用数据

数据用于素材收集与检索、项目与标签管理、摘要整理、AI 生成、项目状态整理、文件导出、备份恢复、跨 AI 交付及本地会员权限验证。

粘贴入库可能自动触发 AI 整理，无需为每条素材再次点击生成。非图片内容在本地规则判断需要生成标题或摘要时会进入摘要队列；例如去掉标题并规范化后的正文超过 200 个字符，或标题规则判断需要 AI。配置有效 API Key 且未使用演示模式时，会向所配置接口发送素材文字、标题和候选项目名称，生成标题、摘要、标签及项目建议；没有 Key 或使用演示模式时执行本地整理。

用户发起简报、汇报、PPT、项目状态生成或 AI 分组等操作时，也会向所配置接口发送相关内容与必要上下文。普通网页收录的规则分类在本地完成，并不等于所有收录行为都调用 AI。

元系不出售用户个人信息，也不将工作素材用于广告定向。当前检查未发现广告 SDK 或开发者远程统计上报接口。

04浏览器权限使用说明

v0.6.1 的 manifest 声明以下权限：

权限用途
activeTab / scripting访问当前操作的网页并执行内容提取或交付所需脚本。
contextMenus提供文字、图片及网页收集的右键入口。
storage保存本地数据与浏览器同步设置。
unlimitedStorage支持较大规模的素材和附件缓存。
tabs获取相关标签页信息、打开目标页面及与扩展页面通信。
downloads根据操作下载和导出文件。
<all_urls> 主机权限支持跨网站内容操作、网页元数据与图片获取，以及用户配置的 AI/Agent 接口访问。

内容脚本会在匹配页面加载时自动注入，而不只在点击扩展图标后注入；manifest 排除 *.google.com 与 challenges.cloudflare.com，且只在顶层页面运行。注入脚本用于划选入口、内容识别和 AI 对话适配等功能。主动保存素材与脚本自动加载是不同的行为；本版本没有申请 history 权限。

您可以在浏览器扩展管理中限制网站访问、停用或卸载扩展。限制权限可能使相关功能不可用。

05第三方服务与数据传输

自带 AI API：模型请求直接发往您配置的 baseUrl，API Key 通过请求的 Authorization 字段发送到该地址。任务内容可能包括文字、标题、来源网址、任务指令、项目名称或项目状态等上下文。默认接口地址为 OpenAI 接口，也支持其他兼容接口及本机模型地址；具体接收方以您的配置为准。连接测试也会发送测试请求及密钥。

网页与图片请求：保存网页链接、补全缺失元数据（包括打开素材库后补全旧链接）时，扩展会请求来源网页及其图标地址；图片收录和外部缩略图展示等操作也可能请求相应资源服务器。链接元数据获取代码使用 credentials: omit，但不代表其他所有请求均不带凭据。目标服务器通常可以收到 IP 地址、请求路径及必要网络信息。扩展并非完全离线。

发送给自定义 AI/Agent：您点击支持直连的自定义目标时，扩展会将所选素材的 JSON 包 POST 到配置地址。该路径发送文字与素材清单，不应理解为一定上传原始附件。其他目标通常通过复制上下文、准备文件并打开目标网站，由您继续粘贴或上传。

浏览器同步：AI 设置（含 API Key）可经浏览器同步服务处理。外部导出与分享：您主动复制、导出并交给其他工具的内容受相应工具规则约束。

第三方可能保留日志、内容或用于模型训练，具体以其政策为准；本政策不承诺其保留期限或删除方式。发送前请核对目标地址、隐私规则与敏感内容。本地优先不等于不向第三方传输。

06AI API Key 的使用与安全

API Key 用于向您选择的模型接口认证请求。当前代码将其作为 AI 设置的一部分保存到 chrome.storage.sync，未发现扩展对密钥进行额外加密后再保存的实现；浏览器存储不等于独立的密钥保险库。

请仅配置可信的接口地址，优先使用 HTTPS；自定义 HTTP 接口不能提供 HTTPS 的传输保护。切换接口时，请确保密钥属于该服务且您信任接收方。可以在设置中移除 API Key 并保存，或启用演示模式，以停止该配置下的真实模型调用；这不会阻止网页元数据等其他联网行为。若疑似泄露，请到服务商平台撤销或更换密钥。

07会员激活与支付信息

Pro 使用激活码在本机通过 WebCrypto 进行 ECDSA 签名及有效期校验；检查的激活、续期及权限判定路径不发起联网验证，也不上传设备标识。此结论仅针对激活路径，不代表整个扩展离线。

本地会员记录包括激活码、首个及最近激活码、订单标识、签发与激活时间、到期日和兑换历史。断开 Pro 或到期仅停用会员状态，代码会保留历史记录，不能视为删除激活资料。

扩展内不收集银行卡号、信用卡号或支付账户凭据。扩展外人工购买激活码所涉及的支付与沟通数据，由实际使用的服务按其规则处理。

08数据保存、删除与用户控制

您可以查看、编辑、归档或删除素材，管理项目，导出和备份资料，调整 AI 设置及连接，并通过浏览器管理站点访问和扩展存储。归档不会删除资料。

素材删除操作移除对应数据库记录，并尝试异步删除附件字节缓存、释放预览地址。缓存删除失败不会阻止界面显示删除完成，因此不承诺一次点击已清除所有字节副本。已授权目录中的文件、导出备份、关联项目时间线、其他历史记录及已生成内容可能仍然保留，需要分别管理；删除素材不会自动删除第三方收到的数据。

会员断开不清除激活历史。浏览器同步设置的删除及传播受浏览器同步机制影响；仅卸载当前设备扩展不应视为撤销密钥或清除所有设备副本。若需彻底停用密钥，请同时在服务商平台撤销。

资料通常保留到您删除、清理对应存储或按所在服务的规则处理。本版本没有统一的自动到期清除承诺。

09数据安全

本地保存减少了集中托管素材的需求，但设备、浏览器、同步账户及网络服务仍可能存在风险。请定期备份，保护设备与浏览器账户，使用可信接口并设置密钥额度，避免发送无权处理的敏感内容，及时更新浏览器和扩展。任何软件均无法保证绝对安全。

10未成年人保护

元系面向工作、学习及知识管理需求。未成年人应在适用法律要求的情况下获得监护人同意，并避免未经授权提交敏感个人信息。

11隐私政策更新

功能或数据处理方式变化时，本政策会相应更新，并在本页面标明版本、更新及生效日期。重大变化将采取适当方式说明。当前政策适用于本次提供的 v0.6.1 代码目录；后续发布包变化应重新核对。
