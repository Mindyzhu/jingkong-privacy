欢迎使用元系（OriginLink）。

元系是一款面向 AI 时代的个人工作素材与上下文管理工具，帮助用户收集网页、文字、图片和本地文件，按照项目整理工作资料，并通过用户自行配置的 AI 模型服务生成工作成果。

我们重视用户隐私与数据自主权，坚持本地优先、用户自主控制、最小必要访问的产品设计原则。

本隐私政策说明元系如何访问、使用、存储和处理相关数据，以及用户可以如何管理自己的信息。

01我们处理哪些信息

1. 用户主动收集的工作素材

当您主动使用元系的网页收藏、文字划选、图片保存或文件导入功能时，元系可能处理以下信息：

  • 网页标题、网址及用户选择保存的网页内容；
  • 用户选中的文字、图片及相关信息；
  • 用户主动导入的本地文件；
  • 用户创建的项目、素材分类、标签及相关工作资料。

上述信息主要用于实现素材保存、项目管理、内容检索及工作上下文整理等功能。

元系的产品设计以用户主动收集素材为基础，不以持续记录完整浏览历史为目的。最终版本是否存在后台读取或其他自动访问行为，尚待代码核实。

2. 用户设置与应用配置

为保证扩展程序正常运行，元系可能在浏览器本地保存以下信息：

  • 用户的功能偏好及界面设置；
  • 用户自行配置的 AI 模型服务地址、模型名称及 API Key；
  • 本地会员激活状态及相关验证信息；
  • 工作目录、项目配置及其他必要的应用数据。

这些信息用于维持扩展程序功能及用户设置。

3. AI 功能处理的信息

元系允许用户自行配置第三方 AI 模型服务。

当您使用 AI 自动标签、内容分析、工作简报、汇报或 PPT 生成功能时，元系可能根据任务需要，将您选择的素材内容、任务指令及必要上下文发送至您配置的 AI 服务商。

相关信息可能包括：

  • 用户选择处理的文字或文件内容；
  • 素材标题、摘要及项目上下文；
  • 用户输入的 AI 任务指令；
  • 完成请求所必需的模型配置与身份验证信息。

自动标签的触发条件尚待代码核实：如果开启该功能后，保存素材会自动触发 AI 请求，那么相关素材内容可能在保存后发送至您配置的服务商。在核实前，本政策不承诺所有 AI 传输都需要逐次点击确认，也不确认自动传输的具体范围。

请注意：使用第三方 AI 服务时，相关数据将受到该服务商隐私政策和服务条款的约束。

建议您在使用前了解所选 AI 服务商的数据处理规则，避免提交不希望交由第三方处理的敏感信息。

02我们如何存储数据

元系采用本地优先的数据管理方式。

用户的素材、项目和相关工作资料主要保存在浏览器提供的本地存储空间中。

元系当前版本不要求用户注册元系云端账户，也不以自有云服务器作为用户工作资料的主要存储位置。

用户可以通过产品提供的备份、恢复及导出功能，自主管理相关资料。

需要注意：

  1. 浏览器数据清理、扩展程序卸载或设备故障可能导致本地数据丢失。
  2. 用户应根据需要定期备份重要工作资料。
  3. API Key 及其他设置实际使用 chrome.storage.local、chrome.storage.sync 或其他存储机制，尚待代码核实。如果使用同步存储，相关字段可能经浏览器服务同步；不能仅凭“本地优先”认定密钥只留在当前设备。
  4. 用户主动导出的文件将保存在用户指定的设备位置，其后续管理由用户自行决定。

03我们如何使用数据

元系仅为实现产品功能及维护必要的运行状态而处理相关数据，包括：

素材收集与管理

保存用户主动选择的网页、文字、图片和文件，支持分类、检索及项目管理。

AI 内容处理

用户发起 AI 任务时，将任务所需内容发送至其自行配置的 AI 模型服务，并展示或保存生成结果。自动标签是否随素材保存触发，尚待核实。

工作成果生成

根据用户提供的素材和指令，生成工作简报、汇报文档及演示文稿。

文件导出与备份

根据用户操作，导出工作素材、上下文及相关文件，方便备份或在其他工具中继续使用。

会员权限验证

通过本地激活码及相应验证机制，确认用户可使用的功能权限。

元系不会将用户的工作素材用于广告定向投放，也不会出售用户的个人信息。

05第三方服务与数据共享

元系当前版本不要求用户将工作资料上传至元系自有云服务器。

但在以下情况下，相关数据可能传输至第三方：

1. 使用第三方 AI 模型

当您配置并使用第三方 AI API 时，相关任务数据将发送至您选择的服务商。

元系无法控制第三方服务商独立开展的数据存储、日志记录或模型训练等行为。

相关规则以该服务商的隐私政策为准。

2. 用户主动导出或分享内容

当您将素材或上下文导出，并自行上传至其他 AI 工具、网站或应用时，后续数据处理由相应服务提供方负责。

3. 浏览器提供的同步服务

如果相关字段使用浏览器同步存储，且您启用了相应同步服务，这些字段可能经浏览器服务提供商同步。哪些字段参与同步（尤其是 API Key），尚待核实。

此类同步遵循相应浏览器服务的隐私规则。

除上述情况及法律法规另有要求外，元系不会主动向无关第三方提供用户的工作资料。

06AI API Key 的使用与安全

元系允许用户自行配置第三方 AI 服务的 API Key。

API Key 用于向用户选择的 AI 服务商发起经过身份验证的请求。

元系不会将用户的 API Key 用于与用户所配置服务无关的用途，也不会主动公开用户的 API Key。

用户应妥善管理自己的 API Key，并根据所选服务商的规则设置必要的使用额度和安全限制。

如果怀疑 API Key 已经泄露，应及时通过对应 AI 服务商的平台撤销或更换。

需要注意，浏览器扩展程序的本地存储并不等同于独立的加密保险库。请避免在不受信任的设备上保存重要密钥。

07会员激活与支付信息

元系提供免费功能及 Pro 会员功能。

根据当前产品说明，v0.6.1 采用激活码方式开通 Pro 权限，并在本地管理会员状态。激活验证是否完全离线、是否存在联网校验或设备信息传输，尚待代码核实，不能据此承诺“完全不联网”。

元系扩展程序本身不要求用户填写银行卡号、信用卡信息或其他支付账户凭据。

如用户通过扩展程序之外的渠道联系开发者购买激活码，相关交易及沟通信息将依据实际使用的支付或通讯服务规则处理。

元系不会将支付账户信息作为素材管理或 AI 功能的必要条件。

08数据保存、删除与用户控制

用户可以在元系中管理自己的工作资料。

根据产品提供的功能，用户可以：

  • 查看、编辑、归档或删除素材；
  • 管理已有项目及相关内容；
  • 导出和备份工作资料；
  • 调整或移除 AI 模型配置；
  • 通过浏览器管理扩展程序及其本地存储数据。

删除素材的具体覆盖范围（包括索引、缓存、附件及其他本地副本）尚待代码核实。本政策不承诺删除一条记录会立即清除所有副本。导出的备份文件需由您另行删除。

但需要注意：

已经发送至第三方 AI 服务商的数据，不会因为删除元系中的本地素材而自动从第三方服务商处删除。

用户如需管理第三方 AI 服务商保存的数据，应按照该服务商提供的规则进行操作。

09数据安全

元系通过本地优先、用户主动操作及必要权限控制等方式，尽可能减少不必要的数据访问与传输。

我们不会要求用户为了使用基础素材管理功能而上传全部工作资料至开发者服务器。

但任何软件、浏览器或网络通信环境都无法保证绝对安全。

建议用户：

  • 定期备份重要素材；
  • 妥善保管 API Key；
  • 避免向不可信的 AI 服务发送敏感内容；
  • 及时更新浏览器及扩展程序版本。

10未成年人保护

元系主要面向有工作、学习及知识管理需求的用户。

如果未成年人使用本产品，应在适用法律要求的情况下获得监护人同意，并避免在未经适当授权的情况下提交敏感个人信息。

11隐私政策更新

随着元系功能调整或相关法律法规变化，我们可能更新本隐私政策。

更新后的版本将通过隐私政策页面公布，并标明最新更新日期。

如果涉及用户数据处理方式的重大变化，我们将采取适当方式进行说明。
